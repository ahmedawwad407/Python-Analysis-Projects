# Sales Data Analysis — Python

Python/Pandas portfolio project using a deliberately messy sales dataset.

## Dataset
`sales_raw.csv` contains sales transactions with intentional:
- duplicates
- missing values
- invalid ages
- zero/negative quantities
- invalid discounts
- invalid prices
- inconsistent category formatting
- mixed date formats

## Tools
- Python
- Pandas
- NumPy
- Matplotlib

We will clean, explore, analyze, visualize, and extract business insights step by step.
